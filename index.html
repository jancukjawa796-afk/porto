Machine Learning Researcher — First Author

Explainable Machine Learning for DDoS Attack Detection with Physical Network Validation

Co‑authored study comparing XGBoost and Random Forest for DDoS detection, combining offline benchmarking on CIC‑DDoS2019 (293,485 flows) with live testing via a working IDS prototype on a physical network. Used SHAP for interpretability and session‑disjoint splitting to avoid data leakage. Offline accuracy reached 99.9%+, but physical testing surfaced a measurable false‑positive rate — showing offline benchmarks alone can't validate real IDS readiness. Published in JOSAPEN, Vol. 4 No. 2, July 2026.
